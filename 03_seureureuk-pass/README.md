# 스르륵패스 유령호출 문제 손실 정량화 및 개선 제안 — 개인 프로젝트 (2026.03)

거주 중인 아파트에 도입된 비콘 기반 자동 출입 시스템('스르륵패스')의 오작동을 직접 관측하고,
대기행렬 기반 엘리베이터 시뮬레이터를 제작해 그 손실을 정량화한 뒤 개선안을 기업에 제안한 프로젝트입니다.

## 문제 정의

이 시스템은 스마트폰과 비콘 사이의 신호 세기(RSSI)만으로 사람을 인식해 공동현관문을 열고 엘리베이터를 호출합니다.
그런데 들어오는 사람과 나가는 사람을 구분하지 못해, **외출할 때에도 엘리베이터가 호출되는 문제**(유령호출)가 있었습니다.

## 1. 실측

- 2주간(2026.03.10 ~ 03.24) 직접 퇴장하며 관측한 결과, **34회 모두 유령호출이 발생**했습니다.
- 지상·지하 여러 층에서 시도했음에도 예외가 없어, 층이나 휴대폰 위치 같은 환경 요인보다는 시스템 구조의 문제라고 판단했습니다.

## 2. 시뮬레이션 — [`elevator_simulator.html`](elevator_simulator.html)

별도 설치 없이 브라우저에서 바로 열어보실 수 있는 단일 HTML 시뮬레이터로, 45층·엘리베이터 4대 단지를 모델링했습니다.

- **배차**: 공동주택에서 일반적으로 사용하는 ETA 기반 군관리 알고리즘
- **물리 모델**: 가속도와 jerk를 반영한 S-Curve 속도 프로필로 실제 주행 시간 계산
- **실험 설계**: 같은 세대 배치·외출 패턴(시드)을 가진 100개 표본에서 스르륵패스 유무를 비교하는 대응표본 t-검정

**결과** (유령호출이 모든 퇴장자에게 발생한다고 가정, 24시간 기준)
- 유령호출 하루 평균 약 1,053회
- 관리사무소 제공 실제 운용횟수 기준, 유령호출이 모두 별도 운행으로 이어지면 운용횟수 최대 약 2.75배
- 전체 이용 시간 +3.72%(하루 +1.99시간), 순수 대기 시간 +4.63%(하루 +1.11시간)

## 3. 손실 추정

- 직접 전력비: 1,053회 × 0.125kWh × 365일 × 200원 ≈ 연 154만 원
- 간접 손실: 운행 횟수 증가로 인한 부품 교체 주기 단축, 배차 효율 저하로 인한 입주민 대기 증가

## 4. 개선 방안

| 구분 | 방안 | 장점 | 한계 |
|---|---|---|---|
| HW | 내부 센서나 현관문 열림 상태가 감지되면 비콘 인식 중지 | 기존 홈네트워크 활용, 높은 정확도 | 단지마다 설비가 달라 일괄 적용이 어려움 |
| HW | 퇴장 동선에 비콘 신호 차폐막 설치 | 매우 저렴, 즉시 효과 | 전파 회절로 인해 정밀 설계 필요 |
| SW | 집 Wi-Fi 연결 해제를 '퇴장 시작'으로 보고 GPS로 2중 확인 | 서버 업데이트만으로 전국 적용 가능 | Wi-Fi 꺼짐, 실내 GPS 오차로 오작동 0%는 어려움 |
