# LG Aimers 9기 — 투구 제구 성공 확률 예측

- **기간**: 2026.06.22 ~ 09.02 (주최 LG AI연구원, 해커톤 주관 데이콘)
  - Phase 1: ML·DL·LLM 온라인 교육 이수
  - Phase 2: 온라인 해커톤 (2026.08.05 ~ 09.02) ← 이 폴더
- **과제**: 투구 직전까지 알 수 있는 정보(볼카운트, 주자 상황, 선수 정보, 과거 이력)만으로 투구별 제구 성공 확률 예측
- **평가**: Brier Skill Score = 100000 × (1 − Brier / 평균 제구율 기준 Brier)
- **제출 방식**: 코드 제출 (`submit/` 폴더를 zip으로 올리면 평가 서버에서 오프라인으로 추론, 10분 제한)

> 대회 데이터와 주최 측 문서·베이스라인 코드는 저작권 문제로 제외했습니다.
> 재현을 원하시는 경우 대회 데이터를 `data/` 폴더에 넣고 실행해 주시면 됩니다.

## 접근 방법

**1. 검증 방식 정립**
테스트 데이터는 2025 단일 시즌인 데 비해 학습 데이터는 2019~2024여서, 랜덤 분할로 검증하면 점수가 크게 부풀려지는 문제가 있었습니다.
그래서 "2024 이전으로 학습 → 2024로 검증"하는 시간 기준 홀드아웃(`validate.py`)을 기준으로 삼았고,
최종 제출 절차 전체를 한 시즌 앞당겨 그대로 재현하는 방식으로 검증했습니다(`experiment5.py`).

**2. 피처** (`features.py`)
- 볼카운트 상황을 반영했습니다. 예를 들어 3볼은 스트라이크를 넣어야 해서 가운데로 몰릴 위험이, 2스트라이크는 유인구를 던질 여유가 있습니다.
- 과거 이력 비율에는 **경험적 베이즈 축소**를 적용해, 표본이 적은 투수·타자의 비율을 전체 평균 쪽으로 당겨 노이즈를 줄였습니다.
- 투수의 최근 폼(최근 1·3·5경기 비율 − 통산 비율)을 추가했습니다.
- 대회 규칙에 따라 모든 변환은 행 단위로, 학습 데이터에서 구한 상수만 사용하도록 했습니다.

**3. 모델** (`model.py`, `train_final.py`)
- 결측치와 범주형을 그대로 처리할 수 있는 `HistGradientBoostingClassifier`를 사용했습니다.
- 최근 시즌일수록 가중치를 크게 주었습니다. (시즌마다 0.85배씩 감소)
- 시즌별 제구 성공률 추세로 2025 기준값을 추정하고, 예측 확률을 그 값에 맞추는 로짓 오프셋 `b`를 학습 시점에 확정했습니다.

**4. 제출 안정성**
- 제출 zip은 `model/`, `script.py`, `requirements.txt` 구조로 고정되어 있어 `features.py`를 함께 넣을 수 없었습니다. 그래서 피처 코드를 `submit/script.py`에 인라인으로 옮겼고,
  복사본이 학습 쪽과 어긋나면 오류 없이 틀린 예측을 낼 수 있어 `check_parity.py`로 두 구현의 출력이 같은지 확인했습니다.
- 커스텀 함수를 Pipeline에 넣어 pickle하면 추론 시 모듈명 `model`이 `model/` 폴더와 충돌해 unpickle이 실패하는 문제가 있어, pickle에는 순정 estimator와 상수(prior, `b`)만 저장했습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `submit/` | 최종 제출물 (`script.py` 추론 코드, `model/model.pkl`, `requirements.txt`) |
| `train_final.py` | 최종 모델 학습 → `submit/model/model.pkl` 저장 |
| `features.py`, `model.py` | 피처 생성, 모델 정의 |
| `experiment5.py` | 최종 절차를 2024 시즌으로 재현한 검증, 보정 함수 |
| `validate.py` | 시간 기준 홀드아웃, 대회 산식 BSS |
| `check_parity.py` | 학습용 피처 코드와 제출용 인라인 피처 코드의 출력 비교 |

아래 명령으로 학습과 검증을 재현해 보실 수 있습니다.

```bash
pip install numpy pandas scikit-learn joblib
python train_final.py      # data/train.csv 필요
python check_parity.py
```
